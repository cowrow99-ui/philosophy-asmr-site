무엇을 하는 앱인가요

철학ASMR 업로더는 유튜브 채널 철학ASMR(@philo_asmr)의 운영자가 자기 컴퓨터에서 실행하는 개인용 도구입니다. 운영자 본인의 채널에 영상을 올리고, 제목·설명·태그·썸네일·공개 예약·재생목록을 설정하는 데만 씁니다.

어떤 정보를 쓰나요

Google 계정 권한(YouTube Data API의 youtube, youtube.upload 범위)으로 운영자 본인 채널의 영상·재생목록만 다룹니다. 다른 사용자의 정보는 모으지 않고, 시청자 정보나 분석 데이터도 가져오지 않습니다.

어디에 저장하나요

권한 토큰은 운영자의 컴퓨터 안에만 저장하며, 서버나 제3자에게 보내지 않습니다. 이 앱은 따로 서버를 두지 않습니다.

공유하나요

어떤 정보도 판매하거나 제3자와 공유하지 않습니다. Google API에서 받은 정보는 위에 적은 용도로만 쓰며, Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다. 이 앱은 YouTube 서비스 약관과 Google 개인정보처리방침의 적용을 받는 YouTube API 서비스를 사용합니다.

권한을 거두려면

Google 계정의 서드파티 액세스 설정에서 언제든 이 앱의 권한을 삭제할 수 있습니다.
